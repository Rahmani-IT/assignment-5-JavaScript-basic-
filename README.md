 Description

This project demonstrates the basics of JavaScript, including objects, calculations, DOM manipulation, event listeners, and dynamic list management.

The project contains three main parts.

 Part 1: Personal Profile

A JavaScript object named userProfile stores the user's information.

The object contains:

 Name
 Birth year
 Developer status
 Hobbies

The program calculates the user's age dynamically using the current year. It also calculates the total number of hobbies.

The profile information is displayed on the webpage.

 Part 2: Create / Update Profile

A form allows the user to enter a username and birth year.

When the form is submitted:

JavaScript reads the input values.
 The program validates the username and birth year.
 The userProfile object is updated.
 The webpage displays the updated profile.
 A success or error message is shown.

Part 3: Tasks and Hobbies List

The user can add a new task or hobby to the list by entering text and clicking the Add Item button.

The Remove Item button removes the last item from the list.

JavaScript updates the list and the total hobby count whenever an item is added or removed.
